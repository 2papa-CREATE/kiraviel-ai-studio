# KIRAVIEL AI Studio v0.7.1

スマートフォン向けの、MV・ASMR・キャラクター物語・ミニチュア・空想空間の制作管理ツールです。`index.html` をGitHub Pages等のHTTPS環境で開きます。外部ライブラリやビルドは不要です。

## 使い方

1. 「新しい作品」を作成し、制作モードを選択します。各モードに3カットの見本があります。
2. 企画・主役・特徴・画風・音の方針を入力します。
3. 「1行ずつカットに追加」はローカルで下書きを作ります。AIは使いません。
4. AIで企画する場合は「ChatGPTへの制作依頼」をコピーしてChatGPTへ渡します。返却JSONを「ChatGPTの絵コンテを受け取る」に貼り付け、確認して追加します。
5. カットの場面・尺・音を調整し、静止画／動画／音のプロンプトを利用します。設定変更後は「更新」を押します。編集済みプロンプトは自動上書きしません。
6. 「OpenArt依頼」をChatGPTに貼り付け、参照画像とともに制作を進めます。これは自動API接続ではありません。
7. 生成サービスと動画編集環境で素材を生成・結合し、完成動画のURL・メモ・状態を記録します。

## 保存と旧版移行

- 保存先は同じブラウザのlocalStorageです。複数端末の自動同期はありません。
- v0.1〜v0.6の作品JSONを「JSONを読み込む」で、既存作品とは別の作品として追加できます。
- 旧版と同じブラウザ／同じオリジンなら「この端末の旧版データを取り込む」も利用できます。旧版のキーは削除しません。
- 新版は独立した `kiraviel_studio_v07` キーを使います。旧トップページは `index-v03.html`、旧v0.6は `kiraviel-ai-studio-v06.html` に保持しています。
- JSONは設定・カット・編集済みプロンプト・メモ・URL・見積を含みます。画像・動画・音声ファイルとパスフレーズは含みません。
- 素材プレビューは一時的です。作品切替・カット再描画・再読み込みで解除されます。素材自体は端末や生成サービスに保存してください。
- 作品削除・読み込み・カット追加・並べ替えなどの直前を1世代保持し、「直前の変更を戻す」で戻せます。それ以後の文字入力も戻るため、必要ならJSON保存してください。
- 最大50作品、各300カット。JSON読込は10MBまで。ブラウザの保存容量が先に上限に達する場合があります。

## AI監督の既存接続

既存の `https://*.workers.dev/storyboard` に、元のMV用リクエスト形式を送る互換機能を残しています。パスフレーズはメモリのみで、ブラウザ保存・JSON保存しません。

- MVモード限定。非MVモードで旧バックエンドに誤送信しません。
- ユーザーの実行確認後に歌詞・設定を送信し、外部API料金が発生します。
- 受信したカットは確認して末尾に追加。既存カットを置換しません。
- 画像・動画生成API、自動素材同期、リップシンク、MP4結合／書出しは実装していません。
- この改修ではCloudflareの既存WorkerやSecretsを変更していません。実際の接続先・認証がこの作業環境にないため、有料APIの実接続検証は未実施です。

## 検証

`node test-core.cjs`

制作モード別指示、旧版移行、JSON往復、異常データの原子的拒否、URL検証、AI JSON取り込み、300カット上限、開始時刻再計算、制作依頼、HTML/JS構造を検証しています。

この環境では対応するブラウザQA機能が利用できなかったため、Android実機での表示・ファイル保存・クリップボード、および既存Workerへの実接続は未検証です。

## v0.7 の修正

- 旧版で複数回ラップされていた画面描画を整理し、重複プロンプト欄を解消。
- 全ジャンルでMV／アニメ／特定メンバーを強制していた指示を、モード別に分離。
- キャラクター条件に加え、物体・素材・空間・スケールを指定可能に。
- 入力中に画面全体を再描画しない保存方式。
- 編集可能な開始秒・尺・比率、並べ替え・複製、予算の手入力集計。
- 複数作品と非破壊JSON移行、手動編集済みプロンプトの保持。
- 動画URLとインポートデータを検証。描画にユーザー由来HTMLは使いません。

## v0.7.1 の追加

- Runway向けの未生成・未課金の準備依頼を出力。
- モデル比較ノート：サービス、モデル、条件、回数、クレジット、円換算費用、採用可否、評価を作品ごとに保存。
- 費用未確認と0円を区別。別サービスのクレジットは合算せず、カット見積とも別管理。
- `starter-projects.json` を読み込むと、ASMR・ミニチュア・動物物語の3企画（各3カット）を追加できます。全て未生成です。
- 保存形式は互換性維持のためversion 0.7のまま。v0.7で読み込むと追加の比較記録は保持されないため、この版を使ってください。
